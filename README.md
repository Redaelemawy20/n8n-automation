# n8n-automation

A collection of n8n automations, each in its own folder with its workflows (as code via [n8n-as-code](https://n8nascode.dev)) and any supporting services.

| Automation | Description |
| --- | --- |
| [order-automation](order-automation/) | Takes customer orders sent to a Telegram bot, saves them to a database and confirms them in Telegram |
